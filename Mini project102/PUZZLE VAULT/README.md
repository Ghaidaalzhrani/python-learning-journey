# 🐍 Python Code Breaker

A small interactive **Python puzzle game** built as a practical application of what I learned in **Python 102**.

The player solves 8 different puzzles by writing Python expressions and earns **100 points** for each correct answer.

---

## 🎯 Project Overview

I created this project to put the Python concepts I learned in **Python 102** into practice by combining them into one interactive command-line game.

Instead of practicing each concept separately, I wanted to use them together in a small project where the player has to actually apply Python to solve problems.

---

## 🧩 Puzzles

The game contains 8 puzzles, each focusing on a different Python concept:

| Puzzle               | Main Concept                  |
| -------------------- | ----------------------------- |
| 🔐 Hidden Message    | String Slicing                |
| 🧹 Corrupted Message | String Methods                |
| 🕵️ Secret Word      | Lists & `find()`              |
| 🔢 Number Laboratory | Built-in Functions            |
| 🔑 Password Matrix   | Nested Lists & `join()`       |
| 🔧 Function Lock     | Functions & Keyword Arguments |
| 🗝️ Key Ring         | `*args` & Argument Unpacking  |
| 🏆 Master Key        | Dictionaries & `**` Unpacking |

---

## 🧠 Python Concepts Practiced

Through this project, I practiced:

* Variables and data types
* Strings and string slicing
* String methods such as `strip()`, `replace()`, and `find()`
* Lists and nested lists
* Built-in functions: `min()`, `max()`, and `sum()`
* `join()`
* Functions and return values
* Default parameters
* Keyword arguments
* `*args`
* Argument unpacking with `*`
* Dictionaries
* Dictionary unpacking with `**`
* `if / elif / else`
* User input with `input()`
* Score tracking

---

## 📊 Scoring System

Each puzzle is worth **100 points**.

With 8 puzzles, the maximum score is:

**800 points**

The game also gives different feedback depending on the final score.

---

## ▶️ How to Run

Make sure Python is installed, then run:

```bash
python main.py
```

Follow the instructions in the terminal and solve each puzzle.
