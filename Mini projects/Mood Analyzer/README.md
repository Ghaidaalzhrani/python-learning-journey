# Mood Analyzer

## About
A beginner Python project that analyzes a user's mood based on positive and negative words found in their input.

## How It Works
1. The user enters how they feel.
2. The program cleans and processes the input.
3. It checks the input against positive and negative word lists.
4. It calculates a score for each category.
5. It displays a result based on the scores.

## Concepts Used
- Variables
- Lists
- Loops
- Conditional Statements
- User Input
- String Methods
- Basic Program Logic
